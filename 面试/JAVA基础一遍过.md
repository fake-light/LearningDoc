# JAVA基础一遍过

1、 序列化和反序列化

​	序列化是将一个对象转为字节流的形式使其支持持久化、网络传输或者缓存的一种手段，反序列化则是将字节流重新转换为一个对象进行使用，需要序列化的对象必须实现xx接口才能进行序列化。序列化时可能使用到的类又OOS（ObjectOutputStream）和OIS（ObjectInputStream）

2、Java中的不可变类

​	所谓不可变类，就是通过final修饰的类，该类不可以被子类继承，不可被修改，同时，该类中的属性必须使用private和final进行修饰，保证其属性同样不可以被修改。因为其不可能被修改的特性，所以他是线程安全的。

3、Exception和Error

​	Exception和Error都继承于Throwable，他是Java中所有异常类的顶级父类，Exception通常是程序可以捕获和处理的异常，而Error通常是系统级的错误，通常是由jvm引发的程序不能进行处理和修复的异常，例如内存溢出，栈溢出等。Exception又可以方位checkedException和uncheckedException，前者是在编译阶段就能检测到的异常，必须对该异常进行处理，否则编译不通过，如IOexception。后者是程序运行过程中产生的异常，如NullpointorException、数组下标越界异常、除零等。

4、Java的优势

+ 一次编译（开发），多平台运行，Java程序的运行依赖于JVM，只要对应的平台能够运行jvm虚拟机，那么开发者只需要编写一套代码，或者编译一次，即可在多个平台进行运行。
+ 面相对象编程，封装、继承、多态的特性使得代码更易于扩展和复用，减少代码冗余，降低程序迭代成本。
+ 生态丰富，拥有很多成熟的框架以及活跃的社区，方便解决遇到的问题。
+ 垃圾回收机制，在设备性能溢出的情况下，自动维护内存的回收释放，让开发者将更多的心思用于需求的实现上。

5、多态

​	多态是指多个类继承或实现同一个接口或父类，并重写其中的共同方法，实例化对象时，使用父类引用指向实际调用的子类，调用时，根据实例化的对象来决定实际调用的具体的逻辑是啥。提升代码的可扩展性以及复用性，降低耦合性。当系统需要扩展时，只需要继承或实现同样的父类及接口并重写里面的方法即可。

6、值传递和引用传递

​	Java中只有值传递，没有引用传递。在对基础数据类型进行传递时，传递的是值的副本，当函数改变其值时，不改变原来的数据。传递引用数据时，因为传递的是引用值的副本，而引用本身只是存储了一个指向堆内引用对象的地址，所以当在函数中对传递的引用进行修改时，原来的对象也会被修改，如果此时将该引用指向另一个new出来的对象，这是是不会修改原来的引用对象的。

7、为什么不支持多继承

​	因为多继承可能会导致实际调用函数产生歧义，例如，当两个类都实现了同一个接口并重写了里面的同名方法，这时，如果又有一个类去继承上面两个类，这时就产生了一个菱形继承的关系，实现该类去调用同名方法时，程序不确定应该使用哪个父类的实现从而产生矛盾。但是Java是支持接口的多重实现的，这是因为在Java8以前，接口是没有默认实现的，不管你继承了多少个接口，你都要重写里面的方法，一切以你重写的为准，但是在8以后，允许在接口内进行默认方法的实现，不过在编译时，如果检测到你实现了多个接口，并且多个接口包含同名的方法实现，就会强制你在当前类中再实现一次，否则编译不通过。

8、面相过程和面相对象编程的区别

​	在所有的编程中，面向过程肯定是基础，因为我们在实现一个需求时，肯定都会有一个明确的流程、步骤。所以所有的语言都是有面相过程编程的思维在里面的，但是面相对象将过程进行了一定的封装，将所有涉及到的东西抽象成了一个类，开发这只需要维护类与类的关系，及其内部实现即可。相比面向过程编程，代码更容易扩展和复用，更适合复杂的模块化清晰的系统，面相过程开发效率更高，但是不易于扩展，更适合小型的、流程清晰的系统。

9、方法重载和方法重写

​	重载是在同一个类中，方法名相同，具有不同的参数类型或个数，是对同一行为不同场景的视线。重写是在继承关系中，子类重写父类的方法，是对父类的一种扩展，实现运行时多态性。

10、Java内部类及其作用

​	内部类是一种定义在类的内部的类。分为成员内部类、静态内部类、局部内部类和匿名内部类。成员内部类可以访问外部类的成员变量，静态内部类只能访问外部的静态成员变量，局部内部类定义在方法内部，只能访问方法内修饰为final的变量，即不可修改的参数。匿名内部类是一种接口的实现方式，适用于使用次数较少，逻辑简单的接口实现。

11、JDK8有哪些新特性

+ 使用元空间代替永久代：这两个都是类的元数据存储管理的实现，原本分别是Jrokit虚拟机和HotSpot虚拟机中的组件，因为oracle收购了Jrokit，所以在8之后jvm虚拟机中就使用元空间代替了永久代的实现。永久代使用的是堆内存，在启动时就限制了占用大小，使用过程中很可能出现内存移除的情况，元空间使用的是堆外内存即系统内存进行存储，可以在启动时指定初始大小和最大大小，一般不用指定，并且永久代的性能没有元空间的性能好。
+ Lamda表达式：提供一种更简洁的方式完成对函数式接口的实现编码，是代码看起来更简洁，更优雅。
+ Stream流式接口：提供一种规范的、简洁的对数据集合进行操作的API，比如需要对集合内的数据进行过滤，或者需要提取集合中对象的某个属性重新生成List。
+ Optional类：更优雅的处理可能产生空指针异常的变量，提供一个容器，可以存储为空或不为空的变量，提供API对其进行判断。
+ 引入新的日期和时间的API：接的日期类因为是可变类导致其线程不安全，新的类是不可变的，可以避免意外的修改
+ 接口可以进行默认实现：更好的将相关方法内聚在接口类，而不用在创建新的对象。

12、String、SBuffer、SBuilder的区别

​	String是一个不可变的存储字符串变量的容器，因为其不可变，所以线程安全。每次对其进行修改都会重新创建一个对象，将创建的对象指向修改的值上，所以如果需要频繁的修改字符串，不建议使用String进行存储。StringBuffer是一个可变的，线程安全的容器，提供方法对存储的字符串进行修改 。

13、Sb的实现

​	底层是一个可变的char数组，然后开放增删改查的API对数组进行操作，当数组容量不够时，将数组容量扩大两倍。

14、包装类型和基本类型

​	包装类型的基本变量存储在栈上，成员变量存储在堆上。包装类型是引用类型，和对象的存储方式一致在堆里面。包装类型涉及到gc会比基本类型的性能低一些。在一些只能对引用类型进行操作的情况下，我们就可以使用包装类型代替基本类型，例如List集合的存储。

# RAG知识库问答

### 1、文档拆分

#### md文档拆分

​	根据md格式将内容拆分为标题-内容的多个段落。

​	因为标题的格式是固定的根据不同的层级在前方加不同数量的#，根据这个特性，撰写正则表达式对内容进行分组

```java
// 使用正则表达式来匹配标题和内容
Pattern pattern = Pattern.compile("(?m)(^#{1,6} .+)([^#]*)");
```

​	该正则表达式会将内容分为标题和数组，遍历匹配的项，每个匹配项中第一组数据为标题，第二组对应为正文内容。

​	对内容进行分段时对当前标题进行缓存，根据层级进行标题的设置，在缓存当前层级的标题时，需要将与当前标题同级或者子级的标题去除，一般来说文档标题层级都是逐步递进的，所以在缓存标题时，越小的标题越靠后，我们只需要匹配出和当前标题同级的标题，将其以及其之后的内容清除即可，正则表达式如下

```java
//  level为当前标题的#数量及层级
String clearTitlePattern = "[#]{"+level+"}.*";
```
